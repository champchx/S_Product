ทุกสัปดาห์

กำหนดสูตรผสมของข้าวแต่ละชนิด ส่วนผสมรวมกันต้องได้ 100%

งานที่ผลิตเสร็จและรอสรุป ใส่น้ำหนัก input / รหัส / ถัง / ผลพลอยได้ / ข้อมูลใบรายงาน ในหน้านี้ที่เดียว แล้วกด “สรุปรายงาน + ส่ง LINE”

ฐานข้อมูลรหัส–ชื่อข้าว ใช้เติมรหัสอัตโนมัติในช่องน้ำหนัก input / สูตร / ผลพลอยได้ และแสดงในใบรายงาน

รายการสถานที่มาของวัตถุดิบ ใช้เป็นตัวเลือก (ดรอปดาวน์) ในช่องน้ำหนัก input และแสดงในใบรายงาน เพิ่มได้ไม่จำกัด

จัดการรายชื่อพนักงาน ชื่อเล่นจะให้เลือกตอนเข้าใช้งาน และแสดงในข้อความแจ้งเตือนทาง LINE
